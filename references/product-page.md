# 商品页尺码表解读

输入可以是用户粘贴的表格文字、截图或链接。截图先读出表格原文再进入下面流程，不要凭视觉印象直接给码。

## 第一步：判定表头语义（决定性一步）

尺码表的数字有两种完全不同的含义，读错必然选错码：

| 语义 | 线索 | 使用方式 |
|---|---|---|
| **成衣实测**（garment measurement） | 表头写"尺码表/产品尺寸/成衣尺寸/item measurements"；数值随码递增 4-6 cm；胸围上限能到 120-130 cm；出现"衣长/肩宽/袖长/裤长"等无法属于人体的项 | 与成衣数据比对，用 `ease` 反算净体需求 |
| **净体/适用身材**（body measurement） | 表头写"建议身材/适合胸围/净体尺寸/body measurements"；数值区间窄（胸围 76-108）；与号型 型 值对齐（如 S 对应胸围 84） | 直接与用户净体数据比对 |
| **身高体重建议** | 出现"建议身高 160-165 / 体重 50-55kg"两列 | 只能作为辅助档，不可单独定码：同身高体重胸围可差 8 cm |

判读不出语义时的探测法：看最小码的胸围。若 S 码胸围 = 84-88 cm 且没有衣长列，几乎必是净体表；若 S 码胸围 ≥ 92 cm 并有衣长，几乎必是成衣表。仍不确定就向用户复述你的判读前提，让确认后再给码。

**混合表**很常见（同一张表既有成衣胸围又有建议体重）。处理原则：以成衣列为定码依据，建议体重列只用于校验离群值。

## 第二步：核对口径细节

- **单位**：cm 还是 inch 列，勿混用；双列以 cm 为准。
- **是否 ×2**：表头写"胸宽/1/2 chest"的是半围，需 ×2 才能与胸围比较。
- **松紧腰**：给"自然态—拉伸态"两个值时用自然态比对净腰围，拉伸态只作舒适上限。
- **公差**：成衣表标 ±1-3 cm 属正常，不要因为 1 cm 差异换码。同款不同色/不同批次可能来自不同工厂，实际可差 2 cm。
- **缺失项**：只有 S/M/L 无 cm → 向客服或详情页索取胸围/衣长实测；拿不到则降级用通用表，并明确声明置信度下降。
- **落肩/插肩**：肩宽项对落肩款无参考意义（数值虚大 5-15 cm），此时以胸围 + 袖长为准。

## 第三步：分品类核对优先级

顺序依据"不可改程度"，不是数值大小。

**上装**：肩宽 → 胸围 → 衣长 → 袖长 → 下摆
- 肩宽和袖窿决定能否穿进去、腋下拉不拉；胸围不够可以选大一码，但肩宽会连带袖长和衣长一起失衡。
- 成人骨架肩宽基本不随体重变化；体重涨主要涨胸围腰围。因此"肩合适但胸紧"应优先选可改的款，而不是加一码。

**下装**：腰围 → 臀围 → 大腿围 → 前裆/裆深 → 裤长
- 大腿围和裆深决定能否蹲下久坐，比裤长重要得多，评论里"穿着不舒服"常出自这两项。
- 腰臀比 > 1.33（臀差大）时，腰到位则臀/大腿必紧，应选后腰打省、松量后移或腰头可调款。

**鞋**：内长/鞋垫长 → 楦宽（脚宽 cm 对照） → 脚背容积
- 先算 脚长 + 0.5～1.5 cm 的内长目标，再看品牌内长表落哪一码，最后才用通用换算表交叉验证。

**内衣**：下胸围（band）→ 罩杯差 → 杯型（全罩/半罩/三角）与乳房形态，肩带与侧比只是舒适度。

## 第四步：模特信息与"参考身形"的使用

模特身高 175 穿 M **不等于**用户 175 该穿 M：模特体重常在 55-62 kg、胸腰差大、肩线窄，属于号型表的极端尾部。把模特信息只用作"衣长/落肩视觉效果"参考，不用作定码依据。

## 第五步：版型与面料修正

读完尺码表后叠加以下修正，再给结论：

- 版型词：修身（松量取区间下限）、常规、宽松/oversize（取上限甚至超出）、直筒（腰臀差小者可穿）、锥形（大腿紧腰松）、阔腿（腰围是唯一约束）、落肩（肩宽项失效）。
- 弹性：氨纶 3-5% 可容忍 4-6 cm 紧量；无弹梭织不可，纯棉针织靠织法而非氨纶提供延展，仍不可按弹力处理。
- 缩水：纯棉未预缩 3-5%、亚麻 5-8%、粘胶 5-8%、羊毛毡缩 8-20%。用 `shrink` 子命令算洗后松量。
- 穿着方式：需要叠穿的外套按大衣档取松量；单穿衬衫按下限。

## 结论输出格式

```
判读前提：<成衣表 / 净体表>，依据是 ___（若判读不确定，此处写明不确定并要求确认）
主选码：X
理由：净胸围 __ → 成衣需 __-__ → 该款 X 码胸围 __（松量 __ cm，<合适/偏紧/宽松>）；肩宽 __（<匹配/偏窄>）
备选：Y 码，适用于 ___（想要更宽松 / 计划叠穿 / 洗后缩水顾虑 / 大腿围余量不足）
风险：___（无则写"无明显风险"）
待补数据：___（缺哪一项会让结论从"确定"降为"区间"）
```

不要在只有身高体重的情况下输出"建议 X 码"这种确定句式，应输出"倾向 X 码，需实测胸围确认"。
