# 通用码数对照表

所有跨系统换算必须先落到 **cm（净体或成衣实测）**，再落码。标签↔标签直译是本领域最大错误来源。

## 鞋码（脚本 `shoe` 同源）

EU 由楦长公式 `1.5 × (脚长cm + 1.5)` 推得，CN 旧码 = `2 × 脚长cm − 10`，JP/中国新码 = 脚长 mm。这三列长度锚定，可互相换算。

| 23.0 | 37.5 | 36 | 230 | 5.5 | 7 |
| 24.0 | 38.5 | 38 | 240 | 6.5 | 8 |
| 24.5 | 39 | 39 | 245 | 7 | 8.5 |

US/UK 各品牌标法互差 ±1（Nike 女=男+1，通用表 +1.5），不要单独引用。**选鞋看商品页"内长/鞋垫长"，取 脚长 + 0.5～1.5 cm。**

## 内衣（女性）

下胸围 cm ÷ 2.5 就近取 65/70/75/80/85/90（CN 与 JP 码）。罩杯 = 上胸围 − 下胸围：10→A，12.5→B，15→C，17.5→D，20→E，每 2.5 cm 一档。

US band 存在两套算法（下胸围直接折英寸 vs 旧派 +4 英寸），这是同一人不同店被报 30B 与 34B 的原因。沟通时只报 **下胸围 cm + 上胸围 cm**。

## 松量（加放量）区间，cm

| 品类 | 常规区间 | 说明 |
|---|---|---|
| T恤/针织衫 | 4-10 | 针织体感比数值宽松 |
| 衬衫（梭织） | 10-16 | 小于 10 抬手会绷扣 |
| 卫衣/帽衫 | 8-16 | |
| 夹克/西装外套 | 10-16 | 需预留内搭 1 层 |
| 大衣/风衣 | 16-26 | 需预留毛衣 |
| 羽绒服 | 18-30 | 含叠穿 |
| 连衣裙（梭织） | 6-14 | |
| 连衣裙（针织弹力） | 0-6 | 可贴身 |
| 裤腰（有扣/腰带） | 0-4 | 一指可插入为宜 |
| 裤腰（松紧/抽绳） | −4 至 2 | 负值靠摩擦固定，需看腰头是否可调 |

含 3-5% 氨纶的弹力面料可额外容忍 4-6 cm 紧量；无弹梭织不可。

## 面料水洗缩水率

| 面料 | 缩水率 | 备注 |
|---|---|---|
| 涤纶/锦纶 | 0-1% | 基本稳定 |
| 真丝 | 1-3% | 冷水，主要风险是失光 |
| 纯棉（预缩/成衣水洗） | 1-3% | |
| 牛仔（含弹力） | 1-3% | 弹力组分久穿变松 |
| 棉涤混纺 | 2-4% | |
| 纯棉（未预缩） | 3-5% | 白色针织可达 6% |
| 粘胶/人棉/天丝 | 5-8% | 湿强低，易变形 |
| 亚麻/纯麻 | 5-8% | |
| 羊毛（可机洗标） | 8-20% | 毡缩不可逆，按 15% 预估 |

纵向（衣长/裤长）缩水通常大于横向（胸围/腰围），但成衣表常只给胸围；按同率估算是保守做法。
