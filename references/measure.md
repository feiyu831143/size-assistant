# 数据采集：净体测量 与 平铺成衣对照

选码准确率的瓶颈通常在数据质量，不在换算。优先争取「平铺成衣数据」，其次才是净体测量。

## 方法 A：平铺成衣对照法（首选，最准）

让用户找一件**同类、且当前穿着合身**的衣服，铺平（不拉伸、缝线对齐、袖放平）测量：

| 部位 | 量法 | 换算 |
|---|---|---|
| 胸宽 | 两侧袖窿底部连线（腋下接缝到下摆最窄处上方）水平拉直 | ×2 = 成衣胸围 |
| 肩宽 | 后中偏左肩缝端点 → 右侧同点直线距离 | 直接 = 成衣肩宽 |
| 衣长 | 后中领口最高点（不含领座）→ 下摆，垂直量 | 直接 |
| 袖长 | 袖窿接缝（肩点）→ 袖口边 | 直接 |
| 腰宽 | 衣身最窄处水平 | ×2 = 成衣腰围 |
| 下摆宽 | 底边水平 | ×2 |
| 裤 腰围 | 腰头两端拉平，自然平铺态 | ×2 |
| 裤 臀围 | 腰头下约 18-20 cm 最宽处 | ×2 |
| 裤 大腿围 | 裆十字缝交点处沿裤腿量 | ×2 |
| 裤长 | 腰头上沿 → 裤脚口外沿 | 直接 |

为什么这个方法优先：它直接产出「目标成衣尺寸」，可与商品页成衣表**同类对同类**比较，绕开所有码数标签、版型命名、面料弹性和个人测量姿势误差。拿到它之后，走 `ease` 子命令判定，不再需要猜松量。

追问话术要具体到"哪件"：不要问"你有尺寸数据吗"，要问"你现在穿哪件上衣最合身？把它平铺，量一下腋下最宽处和肩到肩各多少厘米"。

## 方法 B：净体测量

要求：贴身穿薄衣或裸露测量、自然呼气末读数、尺子贴皮不勒紧（可容一指）、保持自然站姿不吸气不收腹、由他人测量或对着镜子固定起点。

| 部位 | 量法 | 常见错误 |
|---|---|---|
| 净胸围 | 水平绕一圈，过肩胛骨最突出处与前胸最突出处（女性过乳头点） | 尺子前低后高；吸气；软尺未保持水平 |
| 上胸围（armhole） | 腋窝褶皱上方水平绕一圈 | 无弹梭织上装用这个比 bust 更能反映能否穿进去 |
| 下胸围 | 乳房下缘紧贴皮肤水平绕 | 拉紧会小一个 band 档 |
| 净腰围 | 自然腰（肋骨下缘与髋骨上缘之间最细处，约脐上 2 指） | 量在裤腰位置而非自然腰，低腰裤需另量髋上位置 |
| 臀围 | 臀部最突出处水平绕 | 侧身站立未复位；只量侧面 |
| 大腿围 | 坐姿，大腿根最粗处水平绕 | 站姿测量偏小，导致牛仔买不进 |
| 肩宽（人体） | 左右肩峰点（肩关节外上端骨点）直线距离 | 量到三角肌外侧会虚增 3-5 cm |
| 脚长 | 站立、体重压上、脚跟靠墙，量墙到最长趾端 | 坐姿不承重偏短 0.3-0.5 cm；只量一只脚（左右常差 0.3 cm，取大） |
| 颈围 | 喉结下方绕一圈 | 影响衬衫领口 |

## 方法 C：身高体重推算（低置信，仅在 A/B 都拿不到时用）

```bash
node scripts/size.cjs body <身高cm> <体重kg> [--sex female]
```

这是群体回归，男性净胸围误差约 ±3 cm，女性约 ±6 cm（罩杯差异主导，权重不可控）。使用时必须：
1. 明确告知用户这是估算、结论仅到"建议区间"级别；
2. 同时索取品牌成衣表或评论做二次校验；
3. 不要用估算结果去否定商品页给出的成衣数据。

## 数据完整度与置信度对照

| 已有数据 | 可达置信度 | 应输出的结论形式 |
|---|---|---|
| 同类合身衣平铺成衣尺寸 + 目标款成衣表 | 高 | 单一确定码 + 松量数值 |
| 净体三围 + 目标款成衣表 | 高 | 单一确定码 + 需核对的部位清单 |
| 净体三围 + 只有 S/M/L 标签无 cm | 中 | 主选码 + 备选码 + 说明缺哪一项 |
| 仅身高体重 | 低 | 区间 + 追问实测数据 |
| 仅身高体重 + 评论偏码倾向 | 中低 | 区间 + 偏移方向 |

数据不足时，正确的动作是**追问缺失的那一个具体数字**，而不是扩大估算范围或给出更含糊的建议。
